# 猜歌词游戏

一个基于网页的中文歌词猜测游戏，玩家需要根据给出的歌词片段猜出歌曲名称和歌手。

## 功能特点

- 🎵 支持多首经典中文歌曲
- 🎯 交互式歌词填空游戏
- 📊 实时统计游戏进度和完成情况
- 💾 本地存储游戏进度
- 📱 响应式设计，支持移动端

## 游戏玩法

1. 系统随机显示一首歌的部分歌词，其中某些字符会被隐藏
2. 点击隐藏的字符位置输入你认为正确的字符
3. 填完所有空白后，系统会显示完整的歌词和歌曲信息
4. 可以查看已完成的歌曲列表和游戏统计

## 技术实现

- **前端**: HTML5 + CSS3 + JavaScript
- **数据格式**: CSV文件存储歌曲信息
- **样式**: 现代化卡片式UI设计
- **存储**: LocalStorage保存游戏进度

## 文件结构

```
├── index.html          # 主页面文件
├── songs.csv          # 歌曲数据（CSV格式）
├── songs.json         # 歌曲数据（JSON格式）
└── README.md          # 项目说明文件
```

## 歌曲数据格式

CSV文件格式：
```csv
name,artist,lyrics
歌曲名,歌手名,"歌词内容|按行分隔"
```

## 本地运行

1. 克隆或下载项目文件
2. 使用本地服务器打开 `index.html`（由于使用了fetch API加载CSV文件，需要通过HTTP协议访问）
3. 开始游戏
